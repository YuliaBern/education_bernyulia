# ***Просте та сучасне управління завданнями***

Проєкт реалізує клієнт-серверну архітектуру.
Frontend працює у браузері та взаємодіє з сервером через REST API
Backend реалізований мовою Go з використанням фреймворку Gin
Зберігання даних здійснюється у SQLite
Обмін даними між клієнтом і сервером відбувається у форматі JSON

Для запуску треба ввести ці команди
1. go mod tidy
2. go run main.go
