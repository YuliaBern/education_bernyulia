**Короткі теоретичні відомості**

**Прототип сервісу** — це початкова реалізація одного мікросервісу, яка дозволяє перевірити структуру API та взаємодію з базою даних.

**REST API**

REST — це стиль побудови веб-сервісів, у якому використовуються стандартні HTTP-методи:

- GET — отримання даних
- POST — створення
- PUT — оновлення
- DELETE — видалення

Дані зазвичай передаються у форматі JSON.

**CRUD-операції**

CRUD складається з чотирьох базових дій:

- Create — створення
- Read — читання
- Update — оновлення
- Delete — видалення

**PostgreSQL**

Система керування базами даних, яка використовується для зберігання структурованої інформації.

**Docker**

Інструмент для запуску застосунків у контейнерах. Для мікросервісу створюються:

- Dockerfile — опис контейнера
- docker-compose — запуск сервісу + бази даних
